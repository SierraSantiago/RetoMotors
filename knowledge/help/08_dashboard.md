# Dashboard

El Dashboard resume la jornada con leads, asignados, backlog, HOT en backlog, capacidad y avance de gestión cuando estén disponibles. También permite revisar demanda frente a capacidad por punto de venta, además de distribuciones operativas como temperatura y canal.

Los valores del Dashboard representan la jornada consultada y deben revisarse allí para conocer el estado actual; el asistente de ayuda no consulta esas cifras en vivo.
